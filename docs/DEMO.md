# Recording a Demo Video

To successfully sell this web application on marketplaces like CodeCanyon, a high-quality demo video is crucial. Follow these instructions to create a compelling demo.

## Preparation

1. **Clean Environment**: Ensure your desktop is clean. Close unnecessary tabs and applications.
2. **Database Reset**: If you have test data, consider clearing it so the app looks fresh.
3. **Screen Recording Software**: Use software like OBS Studio, Loom, or macOS built-in screen recorder.
4. **Resolution**: Record in at least 1080p (1920x1080) for clear text visibility.

## Video Structure

### 1. Introduction (0:00 - 0:10)
- Start on the application's clean Dashboard.
- Briefly explain what the application does (e.g., "Welcome to the AI SEO Article Generator...").

### 2. The Core Action (0:10 - 0:30)
- Type a realistic, engaging keyword into the input field (e.g., "How to start a successful podcast in 2024").
- Click the "Generate SEO Article" button.
- Highlight the smooth loading state and UI animations.

### 3. Reviewing Results (0:30 - 1:00)
- Once the article generates, scroll through the structured Markdown content to show headings, paragraphs, and formatting.
- Point out the generated Title and Meta Description.
- Move to the sidebar to highlight the LSI and long-tail keyword suggestions.

### 4. Features & Polish (1:00 - 1:15)
- Demonstrate the "Copy All" functionality. Show how the icon changes to a checkmark indicating success.
- Open a blank document or CMS window and paste the content to prove it works perfectly.

### 5. Conclusion (1:15 - 1:30)
- Return to the Dashboard.
- Provide a brief summary of why this tool is valuable for marketers and creators.
- End with a call to action (e.g., "Get the AI SEO Article Generator today on CodeCanyon!").

## Tips for a Great Demo

- **Pacing**: Don't rush. Give the viewer time to read the generated text.
- **Audio**: If you include a voiceover, ensure your microphone is high quality and there is no background noise. If you prefer no voiceover, add upbeat, royalty-free background music and use text overlays to explain features.
- **Highlights**: Use cursor highlighting or zoom features in your video editor to draw attention to specific UI elements (like the "Copy All" button or the keywords list).
