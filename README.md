# AI SEO Article Generator

A production-ready, clean, and well-structured web application that allows users to generate SEO-optimized articles from a keyword using the OpenAI API.

## 🚀 Features

- **Generate SEO Article**: Automatically creates a catchy title, meta description, and well-structured markdown content.
- **Keyword Suggestions**: Generates 5 to 10 highly relevant, long-tail, and LSI keywords.
- **Copy-to-Clipboard**: Easily copy the generated content for publishing.
- **Clean UI**: Built with React, Vite, Tailwind CSS, and Framer Motion for a stunning user experience.
- **Robust Backend**: Powered by Node.js, Express, and MongoDB.

## 📦 Project Structure

- `/backend` - Express API, Mongoose models, and OpenAI integration.
- `/frontend` - React application (Vite + Tailwind CSS).
- `/docs` - Detailed documentation for setup, usage, and demo creation.
