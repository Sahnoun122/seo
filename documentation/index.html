AI SEO Article Generator

Welcome to the AI SEO Article Generator package! This is a complete, production-ready, clean web application that allows users to instantly generate high-quality, SEO-optimized articles based on standard keywords using LLM AI integrations. It features an Express.js API on the backend and a fast React (Vite + TailwindCSS) single-page application on the frontend.

Core Package Features

AI SEO Article Generator

Instantly creates catching titles, optimized meta descriptions, and well-structured Markdown content using advanced OpenAI algorithms.

Smart Keyword Suggestion

Automatically suggests 5 to 10 highly relevant long-tail and LSI keywords to expand your organic SEO keyword indexing.

Premium User UI & UX

Built with beautiful Glassmorphism, smooth animations (Framer Motion), interactive code tabs, and responsive layouts.

One-Click Automatic Installation

This package contains an automated bash setup script install.sh that performs system environment diagnostics, prepares environment files, and downloads all dependencies automatically.

Prerequisites

Make sure you have Node.js (v18+) and npm installed on your machine before running the script.

Step 1

Execute the automated script

Open your favorite terminal at the root directory of the extracted package, and execute the installation command:

Terminal 
bash install.sh
Step 2

Configure the server keys

Open the generated file backend/.env in your favorite editor and configure your OpenAI API Key and MongoDB URI. Refer to the Environment Template tab for descriptions of all available variables.

Step 3

Start the servers

Launch the frontend and backend servers together concurrently with a single command:

Terminal 
npm run dev

Your React App will open at http://localhost:5173, connected directly to your server running on port 5000!

Manual Setup & Configuration Guide

If you prefer to configure, install, and execute backend and frontend components separately, follow this detailed manual procedure.

1. Environment Initialization

Copy environment variable templates in both application scopes to declare settings:

Terminal 
# Create Backend and Frontend local .env configuration files
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env

2. Backend Server Deployment

Step-by-step to start the Express.js API Server engine:

Terminal (Backend) 
# Navigate into backend directory
cd backend

# Install production and development dependencies
npm install

# Start local server with automatic nodemon refresh
npm run dev

The console will log: Successfully connected to MongoDB and Server is running on port 5000.

3. Frontend Client Deployment

Step-by-step to install and start the React Single-Page Application client:

Terminal (Frontend) 
# Navigate into frontend directory
cd frontend

# Install package dependencies
npm install

# Start Vite React server
npm run dev

Vite will spin up the server in milliseconds and present a local link (e.g. http://localhost:5173) for you to view in your browser.

Server Environment Template Configuration

Here is the detailed key list required inside your backend/.env configuration file to wire the application components together:

backend/.env 
# 🚀 Server Port setup
PORT=5000

# 💾 Database URI setup
MONGODB_URI=mongodb://localhost:27017/seo-article-generator

# 🔐 Signed Auth Security Keys
JWT_SECRET=super_secret_jwt_key_change_me_in_production!

# 🤖 OpenAI Large Language Model Settings
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-4o

# ☁️ AWS S3 Cloud Storage Integration (Optional - for Article Images)
AWS_REGION=us-east-1
AWS_ACCESS_KEY_ID=your_aws_access_key_id_here
AWS_SECRET_ACCESS_KEY=your_aws_secret_access_key_here
AWS_S3_BUCKET=your_s3_bucket_name_here

Frontend API Setup

Configure the connection link in frontend/.env to route Axios queries:

frontend/.env 
# API Gateway endpoint from Express.js
VITE_API_URL=http://localhost:5000/api

Application Usage Guide

The AI SEO Article Generator is designed to make organic article indexing fully visual and direct.

Step-by-Step Generation Flow

  1. Start both frontend and backend servers. Open http://localhost:5173 in your browser.
  2. On the main generation Dashboard, type your target primary SEO keyword (e.g., "Best web development frameworks 2026") into the main input form.
  3. Click the Generate SEO Article command button.
  4. A loading screen with an animated status indicator will appear while the backend communicates with the AI engines.
  5. Once generated, the system will displays the fully structured Markdown article and key SEO data blocks.

Output Structure

  • Catchy Title & Meta Description: Displays pre-optimized meta headers ready to paste into your HTML head or CMS.
  • Structured Article: Fully optimized headers (H1, H2, H3), lists, and semantic keywords, styled in premium typography preview.
  • Sidebar Suggested Keywords: Automatically proposes 5 to 10 highly indexed LSI and long-tail keywords to target additional user search intent.

One-Click Copy & Export

Click the Copy All utility button on the top-right of the article card to copy the title, description, keywords, and Markdown content straight to your clipboard, formatted perfectly for your CMS (WordPress, Ghost, Medium, etc.).

Troubleshooting Common Issues

Here are immediate solutions for common installation or execution blocks that users might encounter:

MongoDB Connection Failures

Mongoose Connection Failures

Cause: Local MongoDB daemon is not running or the Atlas IP whitelist block is rejecting queries.
Fix: Ensure your local MongoDB service is started (brew services start mongodb-community or sudo systemctl start mongod). If deploying via Atlas, open security panels and set whitelist IP address to 0.0.0.0/0 for open staging.

Invalid OpenAI API Key Errors

OpenAI Quota/Auth Errors

Cause: Missing billing account card links or invalid key tokens.
Fix: Log in to your OpenAI Developer Dashboard, verify you have generated a fresh key with appropriate permissions, and check your credit balance. If your account runs out of tokens, OpenAI will return a 429 quota exception.

Cross-Origin Resource Sharing (CORS) Blocks

CORS Policy Blocks

Cause: Frontend environment pointing to the wrong URL or port mismatch.
Fix: Open frontend/.env and make sure VITE_API_URL is set exactly to the server root (e.g. http://localhost:5000/api) without a trailing slash.
